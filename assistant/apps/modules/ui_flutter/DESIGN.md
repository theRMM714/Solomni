# ui_flutter 设计

> 画布中心：画布由用户创建，组件经画布"+"进入（规则过滤），
> 布局是用户数据（持久化 + 导入导出）。
> 本文件只规定本模块的呈现设计；scope 与放置规则是全局词汇
> （ui_vocab / ui_canvas），此处不改，只遵守。

## 总览

```
┌─ 左面板（模块列表）────┐┌─ 画布区 ──────────────────────┐
│ conversation           ││ [secrets][+新建画布]           │
│   send（可点击执行）    ││ ┌──────────────┐ ┌─────────┐  │
│ secrets                ││ │ key_input 🔒  │ │ 冻结禁用  │  │
│   set-key（可点击执行） ││ └──────────────┘ └─────────┘  │
│   [创建画布]           ││           [+] 添加组件          │
└───────────────────────┘└───────────────────────────────┘
```

## 左面板：模块列表

- 列出全部有 UI 贡献的模块，每模块：
  - **命令可点击执行**：点击 -> 按声明的参数名逐个弹输入 -> 经 ui.command 路由（与终端 REPL 同一条路）
  - 有私有控件的模块多一个**[创建画布]**入口；已创建则不再显示
- 组件不在这里列出（组件的入口在画布"+"）

## 画布：类型与创建（对应 ui_canvas.CanvasDoc）

| 类型 | ownerModuleId | 创建入口 | 可放置 |
|---|---|---|---|
| 模块画布 | 模块 id | 左面板该模块的[创建画布]，每模块一张 | 本模块私有 + 全部公共 |
| 自定义画布 | null | 画布区[新建画布]，数量不限 | 仅公共 |

- 初始状态：**空白起步**（无保存布局时零画布；空状态提示创建入口在左面板）
- 私有控件在未创建所属画布前不可见（不存在全局组件列表）

## 添加组件：画布"+"

- 选择器内容 = `canPlace` 规则过滤后的全部组件
  （模块画布：本模块私有 + 公共；自定义画布：仅公共）
- 选中后落在默认位置，用户拖动/缩放/删除（现状保留）
- 拖拽只保留画布内位置调整；从面板拖入画布的旧路径废弃

## 离线语义（对齐装卸不变量：降级而非崩溃）

| 场景 | 表现 |
|---|---|
| 模块离线 | 其组件**冻结禁用**：位置/尺寸/样式保持，交互禁用（灰化+标记），不报错不消失 |
| 模块重连 | 组件自动恢复可用（配对推送触发刷新） |
| 从未见过声明 | 占位渲染"未知组件"（现状保留） |

实现：ui_flutter 维护**贡献缓存**（最后已知的组件 kind/label/bind，
每次 discover 刷新；属本模块私有数据）。离线时用缓存渲染禁用态，
声明与缓存皆无才走占位。

## 布局数据（用户数据）

- 自动持久化（LayoutStore，现状保留）
- **导入 / 导出**：LayoutDoc 序列化为 JSON 文件；导入即整体替换当前布局
  （画布 id 重新生成，避免与已存布局冲突）

## 不变的东西

- 组件 id 是模块契约（不可改名，布局只引用）
- scope 规则与放置规则（ui_canvas.canPlace）一字不改
- 事件路由（ui.event -> 声明模块）、配对推送实时刷新（勿轮询）
