# ui_flutter 设计

> 画布中心：导航单元是画布（用户产物），不是模块（提供方）。
> 画布由用户创建（弹窗二选一），组件经画布"+"进入（规则过滤），
> 布局是用户数据（持久化 + 导入导出）。
> 本文件只规定本模块的呈现设计；scope 与放置规则是全局词汇
> （ui_vocab / ui_canvas），此处不改，只遵守。

## 总览

```
┌─ AppBar：assistant [导入/导出] ────────────────────────┐
├─ 画布栏：[secrets🧩][聊天 ▢ ×][＋新建画布][＋添加组件] ──┤
│                                                        │
│              画布区（全宽，自由拖拽布局）                  │
│                                                        │
└────────────────────────────────────────────────────────┘
```

- **没有模块栏**：模块是提供方，不是导航单元；哪个模块在线只通过
  画布内容反映（离线冻结/重连恢复）
- **画布栏是主导航**：点击切换当前画布；每张画布带删除 ×（确认后
  连同放置移除）；模块画布带模块图标徽标
- **命令不出现在 GUI**：命令是文本交互面（ui_cli/REPL）的原生词汇
  （每条命令 = 某组件某事件的文本快捷方式）；GUI 的交互词汇是组件
  本身（key_input 摆上画布即是 set-key 的图形等价物）

## 新建画布：弹窗二选一（对应 ui_canvas.CanvasDoc）

| 类型 | ownerModuleId | 候选 | 可放置 |
|---|---|---|---|
| 模块画布 | 模块 id | 仅含私有组件的模块；每模块一张（已建禁用） | 本模块私有 + 全部公共 |
| 自定义画布 | null | 任意，输标题，数量不限 | 仅公共 |

- 空白起步：模块画布**不预置组件**，与其他画布一样经"+"进入
- 只列含私有组件的模块：public 组件任意画布可放，不需要专属画布；
  这条规则使弹窗候选即"需要专属画布才能看见的东西"
- 删除模块画布后，该模块在弹窗里重新可选

## 添加组件：画布"+"

- 选择器内容 = `canPlace` 规则过滤后的全部组件
  （模块画布：本模块私有 + 公共；自定义画布：仅公共）
- 选中后落在默认位置，用户拖动/缩放/删除（现状保留）
- 拖拽只保留画布内位置调整；从面板拖入画布的旧路径废弃

## 离线语义（对齐装卸不变量：降级而非崩溃）

| 场景 | 表现 |
|---|---|
| 模块离线 | 其组件**冻结禁用**：位置/尺寸/样式保持，交互禁用（灰化+标记），不报错不消失 |
| 模块重连 | 组件自动恢复可用（配对推送触发刷新） |
| 从未见过声明 | 占位渲染"未知组件"（现状保留） |

实现：ui_flutter 维护**贡献缓存**（最后已知的组件 kind/label/bind，
每次 discover 刷新；属本模块私有数据）。离线时用缓存渲染禁用态，
声明与缓存皆无才走占位。

## 布局数据（用户数据）

- 自动持久化（LayoutStore -> 模块内 `userdata/layout.json`，经 user_data 包锚定）
- **导入 / 导出**：LayoutDoc 序列化为 JSON 文件；导入即整体替换当前布局
  （画布 id 重新生成，避免与已存布局冲突）

## 不变的东西

- 组件 id 是模块契约（不可改名，布局只引用）
- scope 规则与放置规则（ui_canvas.canPlace）一字不改
- 事件路由（ui.event -> 声明模块）、配对推送实时刷新（勿轮询）
