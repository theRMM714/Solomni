# 注释契约
> 定位：`.rs` 注释的格式与内容边界：文件头四槽、`pub` 项条目槽、行内限量，以及零豁免的判定方式。
> 效力：规范｜核对：2026-11-17｜依据：`tests/gates/structure/comments.js`、`run-hygiene.js`

## 适用与判据
- 写或改任何 `.rs` 注释前读本文；格式由 T0 的 `commentContract` 判据机器判定（零豁免），内容卫生（悬挂引用这类）另由 `run-hygiene.js` 报，不进 T0。
- 引用只写**文件 + 标题**或顶层节号（本目录各细则的一、二、…节）：不写深层节号，不写缺口 id——那是工作项，会随关账消失。

## 一、只写当前
> 代码注释只描述**当前**情况：这份文件是什么、管什么、不管什么、和谁联动。
> **格式**由 T0 的 `commentContract` 判据机器判定（零豁免，见本文件第五节）；**内容**层面的卫生（悬挂引用这类）另由 `run-hygiene.js` 报，不进 T0。

- 开发历史归 git，待办与路线归 `tests/gaps.yaml`，行为约束归用例——注释里复述它们只会多一份会漂的副本。

- **槽名一律中文 + 全角冒号**：它们是仓库自己的词（`管` / `不管` 就是 `docs/<单元>/README.md` 的节词），译成英文等于给同一个概念造第二份词汇；全角冒号在代码注释里是唯一形态，不必兼容半角。

## 二、文件头（`//!`）

- 每个 `.rs` 文件开头第一段 `//!` 就是文件头（它前面只允许 `#![…]` 内部属性与空行）。**四槽、固定顺序、槽名精确**（全角冒号）：

```rust
//! 目的：这份文件是什么（名词性一句话，不写"为什么现在做"）。
//! 管：职责内侧——它负责什么。
//! 不管：职责外侧——明确不负责什么，尤其是看起来该在这儿、其实在别处的。
//! 联动：契约关系——被谁消费、依赖谁、机制/策略落在哪（用仓库相对路径）。
```

- 槽的值可以续行（续行在 `//!` 后缩进两格）；槽外**不允许**漂浮的散文段。
- 引用只写**文件 + 标题**，或本目录各细则的顶层节号：不写深层节号，不写缺口 id——那是工作项，会随关账消失。

## 三、条目（`///`，只强制 `pub` 项）

- `pub` 项（含 `pub(crate)`、含 `pub` 字段）的文档块：**首行必须是 `目的：…`**，之后每一行**必须是已知槽**或缩进续行——槽外不许有行，散文没有地方藏（`tests/gates/structure/comments.js`）：

```rust
/// 目的：它是什么（一句话）。
/// 参数：`name` 是……（只有含义不明显时才写，一行一个参数）。
/// 返回：……（有返回值才写）。
/// 错误：……（会失败才写）。
/// 约束：调用方必须知道的**当前**事实（不写来历）。
```

- 槽都是可选的，只有 `目的` 必填；不需要别的槽就只有一行。
- 条目层不复用文件头的 `管` / `不管`：那两槽说的是**职责边界**（文件是容器），函数没有这回事。
- 非 `pub` 项与测试的文档块这轮不强制。

## 四、行内（`//`）

- 行内注释只回答"就地为什么"，而且必须**紧贴**它解释的那一行（`node run-hygiene.js`）：

- 连续 `//` ≤ 2 行、单行 ≤ 150 字；中间不许空行，后面必须紧跟代码（成段说明属于文件头或 `///`）；
- 契约、边界、机制位置这类信息只能进文件头或条目的 `///`；
- 禁块注释 `/* */`（判定按词法：字符串、glob、散文里的 `/*` 不算）；
- 历史措辞（曾经 / 原来 / 旧版 / 旧实现 / 改成 / 先是 / 后来 / 以前 / 与旧逻辑）与显式待办标记（TODO / FIXME / 待补）一律不许出现（`node run-hygiene.js`）。<!-- hygiene-ignore -->
- 词表只收**叙事性**词：领域词（`临时 agent`、`后续片段`、`本地遗留`、`暂未暴露`）不算——它们描述的是当前状态。
- 全仓同类措辞由 `run-hygiene.js` 的语义卫生只报（见 `docs/testing/quality-isolation.md`），不进门禁。

## 五、强制方式（零豁免）

- `commentContract` 对**全仓**都判：扫描出的每一处违规都是硬失败，没有存量快照、没有应销账流程，也没有收紧入口（`tests/gates/structure/comments.js`）。
- 门禁只读、不做任何写动作；格式判定与 `node run-hygiene.js` 的报告共用同一份词法。

## 检查
- 格式 → `commentContract`（`tests/gates/structure/comments.js`，零豁免）。
- 内容卫生（历史措辞、悬挂引用）→ `node run-hygiene.js`（只报）。
